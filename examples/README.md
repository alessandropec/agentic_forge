# Examples

Each example folder documents one built-in Agentic Forge component and follows the same structure:

- `README.md`: explains the component and links to the relevant material docs.
- `*_material_doc.md`: documents the general YAML contract of one material type.
- `quickstart.ipynb`: a guided walkthrough with Markdown explanations and runnable cells.
- `materials/`: concrete YAML files and local inputs used by the example.
- `assets/`: optional images or binary files.
