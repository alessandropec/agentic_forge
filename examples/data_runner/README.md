# Data Runner Example

This example shows how Agentic Forge iterates a forged dataset and applies arbitrary processing logic to each item.

## What This Component Does

The data runner component wraps a forged dataset and adds runtime features such as batched iteration and persistent outputs.

## Files In This Example

- `quickstart.ipynb`
  Walkthrough for local processing, persistence, and optional structured-model integration.
- `materials/`
  Concrete runner materials, dataset materials, and output files used by the notebook.
