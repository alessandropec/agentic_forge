# Dataset Example

This example shows how Agentic Forge loads, preprocesses, saves, and reloads JSON datasets.

## What This Component Does

The dataset component forges JSON-backed datasets and keeps the loading format declarative.

## Files In This Example

- `quickstart.ipynb`
  Loads the datasets, preprocesses them, saves them, and reloads them.
- `materials/`
  Concrete dataset YAML and JSON files, plus notebook-generated outputs.

## Material Docs

- [item_dataset_material_doc.md](./item_dataset_material_doc.md)

The material doc describes the general `item_dataset` YAML contract. The example files show concrete `list` and `dict` dataset instances.
